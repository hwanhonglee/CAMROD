# 좌·우 바운더리 곡선 표현 — 2026-10-02

## 요청과 수정

파란 주행 경로뿐 아니라 옆의 초록색 바운더리 자체도 부드럽게 이어지도록 수정했다.
앞선 수정은 선의 끝과 연결 면만 둥글게 했으므로, 원본 폴리라인의 꺾임은 그대로 보였다.
이번에는 **화면용 바운더리 중심선의 꺾임**에 접선 방향으로 연결되는 곡선 구간을 넣는다.

- `navigationBoundaryCurves.js`: 독립된 좌/우 경계마다 화면용 곡선을 생성한다.
  원본 입력을 수정하지 않으며, 표시 곡선의 최대 편차를 **0.12m**로 제한한다.
- `RangerNavigationScene.js`: 초록색 10cm 페인트와 그 아래의 얇은 경계선에
  같은 곡선을 적용한다. 예시 도로 바닥의 가장자리도 함께 부드럽게 표현한다.
- `DrivingDisplay.js`: 미니맵의 바운더리에도 같은 표시 곡선을 적용한다.
  데이터 정규화 단계의 원본 좌표는 변경하지 않는다.
- 각 변경 이유는 코드에 영어 `HH_261002 - ...` 주석으로 남긴다.

## 변경하지 않는 것

지도 파일, ROS 토픽, 경로 계획, 실제 주행 경계·안전 게이트, 객체 바운딩 박스,
캠핑사이트·드롭존 영역, 장식물의 도로 침범 방지 계산은 그대로다.
초록 선의 두께도 기존 **0.10m**를 유지한다.

곡선은 **화면용 근사**이며 원본 측정 경계와 완전히 같은 점들의 집합은 아니다.
끝점과 분리된 경계를 유지하며 끊긴 경계를 임의로 연결하지 않는다.
화면 범례의 툴팁과 외관 보기에서 이 표시용 편차 한계를 확인할 수 있다.
