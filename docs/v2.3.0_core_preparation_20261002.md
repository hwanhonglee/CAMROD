# v2.3.0 순수 CAMROD 변경 준비

2026-10-02 로컬 검증 기록. 이 문서는 태그 발행이나 원격 push 완료를 뜻하지 않는다.

## 포함 기능

- 기존 서비스 UI를 유지하며 배송·호출·복귀 상태의 수신 위치/경로/속도를 주행 화면에 표시.
- 경로가 없을 때도 `/map/markers` 기본 지도 유지. 좌우 경계는 10cm 초록 도색으로 표시.
  도색은 표시 전용이며 경계 좌표나 주행/정지 정책을 변경하지 않는다.
- 중앙 시점, 짐을 실은 로봇 외관, 측정 가능한 객체 크기 표시. 예시 도로·수목은 실제 지형과 구별.
- 정지 예/아니요 확인, 확인 중 미션 세대값 변경 시 취소, Guest 취소 후 재호출 복구.
- 미션·구간별 배송/호출/복귀 거리, 수동 거리, 합계와 플랫폼 상태/CAN·이벤트 기록 복원.
  기존 현장 DB는 원본을 유지하며 모호한 이전 구간은 임의 분류하지 않는다.
- BMS 기반 충전 완료 표시 및 사이트/복귀 방향 전환 시 음성 정책 정리.
- 이미지 누락을 방지하는 단계적 프런트엔드 빌드 게시와 필요한 모델·도색 파일 포함.

인라인 주석은 `HH_YYMMDD - English explanation` 형식을 사용한다. 기능의 실제 작성 날짜와
과거 주석 날짜를 보존한다. 새 보강에는 `HH_261002`를 사용한다.

## 분리 원칙

시뮬레이터 전용 패키지·브리지·맵·제어기·수동 속도 상향·운영시간 우회 설정을 이식하지 않았다.
기존 물리 플랫폼 파라미터, 배터리 임계값 및 주행 알고리즘 기본값을 유지한다.
모델 출처 문서에 제작 경로가 남을 수 있지만 실행 시 외부 시뮬레이터를 요구하지 않는다.

## 실행 및 데이터

기존 플랫폼의 빌드·실행 절차를 사용한다. 프런트엔드는 해당 디렉터리에서 `npm ci`,
`npm run build`로 생성한다. 현장 배포 전 필요한 ROS 패키지를 다시 빌드한다.
기록 파일 형식, 저장 위치와 선택적 수신 전용 CAN 설정은
[미션 기록 가이드](../camrod_ui/docs/mission_recording.md)를 따른다.
실제 로봇 DB에 시뮬레이터 표본을 넣지 않는다.
