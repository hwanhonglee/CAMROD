# UI·수동 개입 후 재개 반영 — 2026-10-02

## 브랜치 분리

- `develop`: 공통 네비게이션 UI, 캠핑사이트·드롭존 표시, 표시용 휠 애니메이션,
  둥근 도로·주변 식물, 화면용 초록 바운더리 곡선과 관련 테스트·시각 자료.
- `virtual/carla`: 같은 공통 UI에 CARLA 전용 수동 제어·명시적 자율 재개 기능을 더한다.
  수동 재개 패널·백엔드·launch 연결은 `develop`에 옮기지 않는다.

## 수동 개입 후 재개

`ManualMissionResume.js`와 `manual_mission_resume.py` 및 `ui_backend_node.py`가
진행 중이던 도로 구간 미션의 사이트·방향·토큰을 보존한다. 수동 제어를 해제하는 것만으로
자동 재개하지 않으며, **자율주행 재개** 버튼을 명시적으로 눌러 현재 위치에서 재요청한다.

이 기능을 켜기 전에 취소된 미션은 복원할 수 없다. 주차·도킹 같은 정거장 기동 단계도
도로 구간 재개 대상으로 간주하지 않는다. 새 미션, 유효하지 않은 토큰, 오래된 피드백,
미완료 취소, 활성 수동 제어 또는 미준비 상태에서는 요청을 거절한다.

피드백 시간은 2초 이내, 속도·각속도는 각각 절댓값 0.03m/s·0.03rad/s 이하여야 한다.
일반 UI의 `manual_mission_resume_enabled` 기본값은 `false`다. CARLA 실행 경로에서
명시적으로 전달한다. 미션 기록에는 기존 맥락을 이어주는 메타데이터를 전달한다.
영어 `HH_261002 - ...` 주석으로 변경 이유를 코드에 기록했다.
