# 실제 178° 회전 중 처음 약 90.42° 부분구간

**90° 명령 후 정지 시험이 아니다.** 기존 B1 주행 기록의 약 178° 연속 회전에서 처음 90°를 통과한 부분만 분석했다.
새 차량 조작·제어 변경·실험은 없으며, 앞서 기록한 Drop Zone −77.693°의 `NOT_A_90_DEG_TEST` 결과는 그대로다.

## 구간을 고른 방법

GNSS 오차를 보기 **전에**, CARLA truth의 회전량과 차체 이동만으로 선정했다.
각속도 절댓값 >1°/s인 활동을 간격 ≤1초로 연결하고, 전체 회전 ≥90°, 전체 차체 누적 경로 ≤0.15m,
truth 표본 간격 ≤0.5초인 가장 이른 연속 구간을 선택했다. 그 안에서 누적 yaw가 처음 90°를 넘는 **실제 원본 표본**에서 잘랐다.
오차가 작은 중간 구간을 찾아 선택하거나 좌표·각도를 보간하여 90°로 맞추지 않았다.

- 전체 회전: 2026-09-09 **01:32:28.934659~01:32:37.932376 KST**, −178.176376°, 차체 누적 경로 0.097301m.
- 선택 부분: 같은 날 **01:32:28.934659~01:32:33.444187 KST**, 4.509528초, **−90.416908°**.
- 원본 JSONL 행(1부터): **5984~6293**. truth 표본 인덱스(0부터): **1660~1746**, 87개.
- 실제 truth header timestamp: `1788885148.9334946~1788885153.4427192`초. 수신 monotonic/UTC와 전체 구간 끝 인덱스도 JSON에 보존했다.
- 마지막 선택 표본에서 차량은 정지하지 않고 이후 약 178°까지 계속 회전했다.

## 실제 GNSS 중심 보정 수치

| 측정 | 시작→종료 변화 | 구간 최대 |
| --- | ---: | ---: |
| 원시 안테나 위치, 독립 local ENU | 62.438cm | — |
| 실제 CARLA 차량 중심, map | 4.179cm | 누적 경로 4.697cm |
| 보정 직후 GNSS 중심, map | 3.191cm | — |
| 최종 localization 중심, map | 2.601cm | — |
| `(보정 중심 − 실제 중심)` 오차벡터 변화 | **1.352cm** | **1.624cm** |
| `(localization 중심 − 실제 중심)` 오차벡터 변화 | **1.907cm** | **1.975cm** |

안테나 원시 좌표의 약 62cm 궤적이 로봇 중심의 62cm 이동으로 전달되지는 않았다.
그러나 실제 차체 중심도 4.18cm 이동했으므로 map 좌표가 완전히 고정되는 실험은 아니며,
보정 오차 변화도 0은 아니다. 보정 중심의 최대 **절대** truth 오차는 6.626cm, localization은 6.070cm다.
이 절대 정합 편차와 회전 중 오차벡터 변화는 별개 지표다. 임의 허용 오차로 GNSS `PASS`를 추가하지 않는다.

raw GNSS 43개/heading 43개가 연속 수신됐고 최대 간격은 각각 112.9/114.8ms다.
truth 87개의 최대 간격은 64.8ms다. corrected↔truth 43쌍의 최대 시간차는 5.929ms,
localization↔truth 90쌍은 31.083ms다. 10Hz GNSS 경계 공백은 최대 약 54ms로,
마지막 truth 표본과 GNSS가 정확히 동일 시각에 발행됐다고 가정하지 않았다.
세 중심 pose는 모두 `map`, 원시 GNSS 그림은 별도 ENU 패널이다.
