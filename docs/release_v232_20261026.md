# CAMROD v2.3.2 — 관리자 복구와 진단 화면

<!-- HH_261026 - Release only native CAMROD changes on the existing develop history; preserve safety defaults and distinguish unit evidence from field validation. -->

기준은 원격 develop/v2.3.1의 `e9876b1232efae8c57c90f5c12a6f871018f12e1`이다.
가상환경 브랜치 전체를 병합하거나 파일을 통째로 덮어쓰지 않고 이번 변경만 이식했다.
기존 태그는 이동하지 않으며 새 annotated tag는 `v2.3.2`다.

## 수정 내용

1. 조건부 무입력 10초 후 대기 화면으로 돌아가던 UI 타이머를 제거했다.
   사이트 자동복귀 기본값은 원래 false였고 그대로다. 최소 하역 정지 5초는 이용 제한
   시간이 아니며, B1–B13 배송/호출 대기는 명시적 복귀 요청을 기다린다.
2. 관리자 안전정지·복구 초기화 카드, 인증 API와 native Trigger 서비스를 추가했다.
   현재 미션/주행 권한을 정지·취소하고 Nav2 취소 완료와 실측 정차를 확인한다.
   현재 장애물, 오래된 센서 근거, EStop, 플랫폼 오류는 우회하지 않는다.
   초기화 후에도 정차하며 별도 출발 명령이 필요하다.
3. 관리자 진단을 주행·안전 / 센서 / 지도·인지 / 주차·도킹 / 시스템으로 분류했다.
   기존 9개 화면과 명령은 유지하고 안전·제어를 명령 권한 / 미션 / 진단으로 나눴다.
   실제 정지 사유와 누락 구성 요소는 표시하며 긴 원문만 펼치기로 보존한다.
   휴대폰에서는 관리자 메뉴의 최소 글자 크기를 보장한다.
4. 기존 native 제어기·플랫폼 상태 구독을 재사용했다. 시뮬레이터 수동주행·재개 기능,
   센서 대체 영상, 가상환경 프로필·토크·속도·지도·자동 목표 재전송 설정은 추가하지 않았다.
   원래 배터리 정책, motion watchdog, 기본 주행 설정도 바꾸지 않았다.

새 동작과 이식 차이에는 영어 `HH_261024 - ...` / `HH_261026 - ...` 주석을 남겼다.
다른 작업트리의 vendor 변경, 이전 주석 작업, 데이터베이스·로그·임시 실험 파일은 제외했다.

## 버튼 위치와 사용

관리자 로그인 → **주행·안전 → 안전·제어 → 명령 권한 → 안전정지·복구 초기화**.

정차하고 장애물/비상정지/장비 상태를 확인한 뒤 초기화 요청과 최종 확인을 누른다.
성공 메시지는 `recovery_hold_reset_motion_disarmed`다. 현재 미션은 종료되며
저절로 재개하지 않는다. 거절되면 화면에 표시된 원인을 먼저 해결한다.

- HTTP: 인증 GET/POST `/api/admin/safety/reset`, POST body `{"confirm": true}`.
- ROS: `/control/cmd_vel_safety_gate/reset_recovery_hold`, `std_srvs/srv/Trigger`.
- [native 백엔드 이식 설명](../camrod_ui/docs/admin_safety_reset_native_port_20261026.md).

## 실제 장비에 적용

기존 환경·센서 설정은 유지한다. 장비를 안전하게 정차·미션 종료한 뒤 소스를
갱신하고 필요한 패키지를 빌드한 후 평소 native bringup으로 재시작한다.

```bash
git fetch origin develop --tags
git switch develop
git pull --ff-only origin develop
# 또는 배포 버전 고정: git switch --detach v2.3.2
./colcon_build.sh --packages-select camrod_control camrod_ui camrod_bringup camrod_planning
```

기존 실행 바이너리에 서비스가 저절로 추가되지는 않는다. 서비스 미가용이면
빌드/설치 overlay와 실제 실행 노드 버전을 확인한다. 기존 실증 데이터는 삭제하거나
이식하지 않았고 데이터 형식도 이번 작업에서 바꾸지 않았다.
