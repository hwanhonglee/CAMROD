0. v2.1.4 최종 optional runtime·경계 복구 확인 [DONE-CODE, DONE-SIM]
- HH_260805 - LiDAR cost-grid는 운영 기본 `false`다. 실제 full sim에서
  `/sensing/lidar/lidar_cost_grid` 노드는 없고 `/sensing/cost_grid/lidar`
  publisher는 0개였으며, cost checker는 radar와 inflation만 감시했다.
  system graph에서 해당 optional node/topic만 제외한 상태로
  `/system/status.system_ok=true`를 확인했다.
- 같은 launch를 `enable_lidar_cost_grid:=true`로 실행하면
  `LidarCostGridNode` 하나가 `lidar_processing_container`에 적재되고
  transient-local publisher 1개가 생겼다. 즉 코드와 component는 유지하되
  사용하지 않을 때 진단 ERROR를 만들지 않는다.
- 시스템 checker component 등록은 24개 모두 유지했지만, 반복 full-stack
  종료에서 localization과 autonomy component process의 간헐적 `-11`과
  isolated-container 종료 hang을 재현했다. 운영 기본은 검증된 24개
  standalone checker이고 `use_checker_components:=true`는 bench 전용이다.
- map v15 동적 recovery에서 route/static case는 `REVERSE_YAW_RIGHT`, 최대
  `0.05 rad/s`, 이동 `0.0582/0.0405 m`였고 재접촉 `0.335/0.400 s` 뒤
  latch됐다. one-side case는 `CRAB_LEFT`로 `0.3378 m` 이동했고 모든 최종
  command는 zero였다. 이는 fail-closed sim 증거이며 실차 완료가 아니다.
- 최종 기본 full sim은 steady-state 79 ROS node에서 `[SYSTEM] OK`에 도달했고 Robot/Guest
  HTTP 200 응답은 약 7/6 ms였다. Ctrl+C에서 24 checker와 UI/Nav2/control
  process가 모두 clean exit했다.
