0H. HH_260819 Return 선점·B11-B13 전방 순환·UI lease 경량화
    [DONE-CODE, DONE-SIM, MEASURED-AMD64, FIELD-PENDING]
- Robot diagnostics의 `Return`과 Docking 화면의 `즉시 복귀`를 같은
  `/ui/manual_return` 권한으로 통합했다. 일반 outbound Nav2 주행에서는
  cancel, mission/drive gate OFF, `0.50 s` 정지, gate ON, 단일 return recall
  순서로 전환한다. 연속 클릭은 preempt/return latch에서 합쳐진다.
- B1-B10은 campsite에서 180도 선회 후 reverse-shortest 복귀를 유지한다.
  B11-B13은 `0.30 m` roadside crab 후 `CRAB_OUT -> DONE`까지 원래 heading을
  유지하고 `done_roadside_forward` source로 전방 one-way loop를 선택한다.
  좁은 lane에서 시도했던 zero-turn은 `lanelet_physical_body_cost` 접촉 때문에
  제거했다. Static lanelet bypass는 명시된 campsite phase로만 제한되고 live
  obstacle은 계속 정지한다. `DONE` 뒤 ordinary route에서는 physical-body와
  planning-footprint lanelet stop이 다시 fail-closed로 적용된다.
- 현재 사용자 map SHA `8fa131...e59`의 격리 AMD64 graph에서 B1-B10
  turnaround exit 10/10, B11-B13 roadside exit 3/3이 통과했다. B11 full
  cycle은 UI Return, `155.73 m` 전방 loop, drop-zone yaw alignment, reverse
  parking, `WAITING_FOR_CHARGING -> CHARGING`, internal `PARKED`까지 통과했다.
- 일반 B6 outbound가 `2.019 m` 이동한 뒤 실제 `/ui/manual_return`을 연속
  호출했다. 출력은 `5.01 ms`에 zero, `0.10-0.45 s` hold 구간 최대 명령은
  `0.000`, recall은 `0.508 s`에 1회만 발행됐고 `2.133 m/12 pose` reverse

  drop-zone state handoff와 canonical config만 소유한다.

  ROS GuardCondition과 1 Hz abandoned-expiry timer로 교체했다. 실제 표시

0G. HH_260810 관리자 화면 유지·10 Hz telemetry·복귀 경고 분리

  화면 분기 밖으로 이동했다. waiting, manual/campsite driving, arrival, return,

  close를 감지한다. heartbeat가 끊기면 12초 timeout으로 high-bandwidth ROS
  subscription을 해제한다. send-only socket이 구독을 영구 유지하던 실측 중
  발견 문제를 수정했다.

  `9.938 Hz`, interval p95 `100.792 ms`, max `101.295 ms`였다. CPU는 idle
  `1.00%`에서 active `1.12%`, RSS는 `76,696 -> 77,592 KiB`; normal close
  release는 `83.3 ms`, heartbeat 없는 lease는 `12.078 s`에 해제됐다.
- planning nav checker는 RETURNING_TO_DROP_ZONE 전체를 정상으로 숨기지 않는다.
  전환 전 관측된 Nav2 goal UUID만 3초 handoff 대상으로 보존하며, 새 return
  goal의 ABORTED는 3초 안이어도 WARN 대상이다. 따라서 사용자 로그의 이전
  goal terminal entry는 지우되 실제 복귀 경로 실패는 계속 표시한다.
- UI 측정 JSON과 system handoff 정책 JSON에서 대표 PNG/GIF를 재생성하는
  중앙 renderer를 추가했다. UI 이미지는 AMD64 standalone 측정 요약, system
  이미지는 source/config/unit `POLICY REGRESSION`으로 표시하며 raw runtime이나
  실차 capture로 오인할 수 없게 각 이미지와 README에 제한을 명시했다.
- 중앙 offline renderer `12/12`를 실행 가능한 설치 entrypoint로 확인했다.
  기존 historical-summary renderer의 빠진 source execute bit를 수정했고,
