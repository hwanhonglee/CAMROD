CAMROD · camrod_platform 신규 기능

전조등 · 방향지시등(WS2815) 제어 — 구현 설계서

UI 전조등 버튼, lanelet turn_direction 태그 기반 방향지시, ERROR_STOP/estop 비상등을 Arduino Nano 경유로 제어하는 기능의 확정 설계와 작업 순서.

설계 결정 12건 확정 — 미해결 없음 지도 태그 검증 완료 (left 53 · right 77) 플래너 확장 코드 검증 완료 (§2) 구현 언어 C++ 통일 확정

lanelet_route_planner(C++)가 경로 계산 시 턴 구간을 함께 발행하도록 확장 (/planning/route_turn_segments, Float32MultiArray). 실코드 확인 결과:

① createPlan의 경로 생성 루프(205–220행)가 lanelet별 호길이 구간을 이미 계산 중 (segment_start_s/segment_end_s) — 누적 변수 하나로 전역 [S₀,S₁] 산출 · ② 태그는 루프 안에서 attributeOr("turn_direction","") 한 줄 · ③ route_lanelet_ids 발행(HH_260619)과 동일한 transient_local 퍼블리셔 선례 존재. 경로 계산 로직은 한 줄도 안 건드리는 순수 additive 변경, 약 40–60줄.

동기화 가드: 배열 첫 요소에 전체 경로 길이를 넣고, light_controller가 수신한 global_path 길이와 대조(±1 m). 불일치 = 경로 교체 순간의 신구 혼합 → 해당 사이클은 소등 유지.

3방향 판정 — 호길이 기반 턴 구간 매칭

플래너가 발행하는 턴 구간은 경로 시작점 기준 호길이(s)로 표현됩니다: [0]=전체 경로 길이, 이후 [방향(+1 좌 / −1 우), 시작 s₀, 끝 s₁] × N. 라이트 노드는 로봇 위치를 경로에 투영해 현재 s만 계산하면 되고, 수신한 global_path 길이와 [0]이 ±1 m 이상 어긋나면(경로 교체 순간의 신구 혼합) 그 사이클은 소등을 유지합니다.

그림 1 — 판정 규칙. 로봇의 현재 호길이 s가 턴 구간 시작 12 m 앞(D_pre)에 들어오면 점등, 구간 끝 s₁을 지나면 소등. 각도 계산·임계값 튜닝이 전혀 없다 — 지도 태그가 곧 정답지.

램프 모드 우선순위 (light_controller)

1 ERROR_STOP or estop(HW/소프트) HAZARD 점멸
2 크랩 기동 중 (site_maneuver 활성 + |linear.y| > 0.05) 이동 방향 지시
3 턴 구간 D_pre 진입 ~ 통과 전 태그 방향 지시
4 그 외 (그리드 폴백 주행 포함) 소등

전조등은 이 우선순위와 무관한 독립 채널 (UI Bool 그대로 통과).

5시리얼 프로토콜 & 페일세이프

PC → MCU (5 Hz, 개행 종료):   {"h":1,"i":"L","q":42}
                               h = 전조등 0/1
                               i = 인디케이터 O(off) / L / R / H(hazard)
                               q = 시퀀스 번호

MCU → PC (1 Hz):               {"a":42,"h":1,"i":"L","e":0}
                               a = 마지막 수신 q (ack) · e = 에러코드

그림 2 — 페일세이프. "최초 프레임 이후부터만" 두절을 판정하므로 PC 부팅/노드 재시작 구간에서는 비상등이 오점등하지 않고, 주행 중 실제 두절 시에만 HAZARD가 켜진다.

6하드웨어 주의사항

✓ 릴레이 D10 확정 — D13 부트로더 점멸 문제 해소

D13은 부트로더가 리셋/업로드 시 점멸시키는 핀이라 릴레이가 순간 클릭될 수 있었음 → D10으로 변경 확정 (D12에서 재변경, 2026-07-08). 잔여 주의: 리셋 중 모든 핀이 잠깐 입력(플로팅) 상태가 되므로 릴레이 모듈은 풀다운 있는 active-HIGH 타입 권장 (벤치에서 확인).

WS2815 전원/신호

스트립 전원은 12 V 별도 공급, 데이터 신호는 5 V (Nano 직결 가능), GND 공통 필수. D6/D8 백업(BI) 라인은 스트립 자체 리던던시 기능 — FastLED 코드는 D5/D7만 구동하고 백업은 병렬 배선만 하면 됨.

시리얼 포트 충돌 방지

Nano(CH340)는 ttyUSB*로 잡혀 레이더 CH9344 7채널과 열거 순서가 섞일 수 있음 (현 포트맵: FRONT1=USB0 … REAR=USB6). 반드시 /dev/serial/by-id/ 고정 경로 사용.
